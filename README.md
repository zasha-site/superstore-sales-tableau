# Superstore Sales Analysis (Tableau)

An interactive Tableau workbook analyzing retail sales performance — orders, customers, regions, and product categories.

## 📂 Project Files

| File | Description |
|---|---|
| `classworktask.twbx` | Tableau packaged workbook (data + visualizations) |

## 📊 Dataset Overview

- **Rows:** 9,800 orders
- **Unique orders:** 4,922
- **Unique customers:** 793
- **Total Sales:** $2,261,536.55
- **Average sale per line item:** $230.77

## 💡 Key Insights

- **Technology** is the top-selling category ($827,456), followed by Furniture ($728,658) and Office Supplies ($705,422)
- The **West** region generates the highest sales ($710,220), followed by East ($669,519), Central ($492,647), and South ($389,151)
- **California** is the top-selling state ($446,306), followed by New York ($306,361) and Texas ($168,572)
- The best-selling individual product is the **Canon imageCLASS 2200 Advanced Copier** ($61,600 in sales)

## 📈 Included Views

- Sales by State
- Sales by Sub-Category
- Sales by Category
- Sales by Region
- Sales over Time
- Total Orders / Total Customers / Total Sales (KPI views)
- Average Order Value
- Top 10 Customers
